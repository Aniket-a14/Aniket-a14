## About

I build intelligent systems — bridging systems-level C++ with modern AI agents and full-stack architectures. Most of my recent work lives in [Wizard](https://github.com/Wizard-AIA), a local-first autonomous data-analysis agent, alongside a handful of other AI-native tools across the stack. I'm working toward scalable distributed systems and domain-specific, fine-tuned LLMs — and I'm open to collaborating on either.
